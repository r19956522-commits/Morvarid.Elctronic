محمدرسول یزدیان کد دانشجویی: ۴۰۳۲۲۲۱۰۷۳
جدول درستی (Truth Table)
A15 A14 محدوده آدرس (Hex) حافظه فعال CS0 (ROM1) CS1 (ROM2) CS2 (RAM1) CS3 (RAM2) عملیات
0 0 0000H - 3FFFH ROM 1 0 1 1 1 فقط خواندن (RD)
0 1 4000H - 7FFFH ROM 2 1 0 1 1 فقط خواندن (RD)
1 0 8000H - BFFFH RAM 1 1 1 0 1 خواندن / نوشتن
1 1 C000H - FFFFH RAM 2 1 1 1 0 خواندن / نوشتن
معادلات منطقی انتخاب حافظه (Chip Select)
حافظه معادله منطقی توضیح
ROM 1 CS0 = NAND(A15', A14') وقتی هر دو A15 و A14 صفر باشند، خروجی صفر (فعال) می‌شود.
ROM 2 CS1 = NAND(A15', A14) وقتی A15=0 و A14=1 باشد، خروجی صفر (فعال) می‌شود.
RAM 1 CS2 = NAND(A15, A14') وقتی A15=1 و A14=0 باشد، خروجی صفر (فعال) می‌شود.
RAM 2 CS3 = NAND(A15, A14) وقتی هر دو A15 و A14 یک باشند، خروجی صفر (فعال) می‌شود.
